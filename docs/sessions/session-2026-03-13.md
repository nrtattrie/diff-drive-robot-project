# Session 2026-03-13 (continued)

## SSH Issue: RESOLVED

Root cause found and fixed after context clear + resumed troubleshooting.

**Root cause:** NordVPN's network extension was running on Mac even when "disconnected." `ifconfig | grep utun` revealed 9 active `utun` interfaces. Routing table had a **reject route (`!`)** for `192.168.68/22` — silently blocking all LAN traffic before ARP was ever sent.

**Fix:** Fully quit NordVPN from menu bar → reboot Mac.

**Permanent solution: Tailscale** — replaced raw LAN SSH entirely.
- Pi: `curl -fsSL https://tailscale.com/install.sh | sudo sh` + `sudo tailscale up`
- Mac: Tailscale app installed, same account, `ssh pi` alias in `~/.ssh/config` pointing to Pi's `100.x.x.x`
- Works regardless of NordVPN state, IP changes, or mesh topology
- Documented in `docs/troubleshooting/ssh-mac-to-pi-2.md`
- Memory updated: `project_ssh_tailscale.md`
